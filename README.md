# Электронная торговля.

## Описание:

Ядро для интернет-магазина.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/VanAlex278/VanAlex278Repo
```
2. Установите зависимости:
```
pip install -r requirements.txt
```

## Использование:

Имеются классы:

- Product - продукт.
- Category - категория.
- Smartphone, LawnGrass - подклассы класса Product

## Тестирование:

Все функции проекта протестированны с помощю pytest.
